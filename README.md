# D.A.B.S.y 🤖

D.A.B.S.y is an AI desk and study companion designed for Class 11 students.

## What D.A.B.S.y does

- 🧠 Gemini-powered AI conversation
- 🎙️ Voice input
- 🔊 Spoken responses
- 👀 Animated desk-companion face
- 📚 Study Mode
- 📱 Installable PWA
- 💾 Local app settings
- ⚡ Service-worker caching
- 🌑 Minimal black-screen interface

## Controls

### Single tap
Start talking to D.A.B.S.y.

### Double tap
Open the control bubbles.

### Study
Toggle Study Mode.

### Settings
Connect Gemini.

## Study Mode

When Study Mode is enabled, D.A.B.S.y focuses on:

- Clear explanations
- Step-by-step solutions
- Class 11 Science concepts
- Examples
- Understanding rather than simply giving answers
